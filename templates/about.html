About This System

The Placement Prediction System evaluates candidate placement probability and predicts expected salary based on academic and experience profiles.

How It Works

The system uses two trained machine learning models:

  • Placement Model: Predicts whether a candidate will be placed based on academic scores, projects, internships, certifications, and skills.
  • Salary Model: Predicts expected annual compensation (in LPA) for placed candidates, using the same features plus placement status.

Input Features

  • CGPA (0-10 scale)
  • 10th and 12th percentage scores
  • Active backlog count
  • Major and minor project counts
  • Internship experience (yes/no)
  • Hackathon participation (yes/no)
  • Technical certifications count
  • Technical skills count
  • Communication skill rating (0-10)

Technical Details

Built with Flask, scikit-learn, and pandas. Models are trained on historical placement data and serialized as pickle files for inference.
